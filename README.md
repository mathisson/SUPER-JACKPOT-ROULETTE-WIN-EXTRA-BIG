## 🚀 HOW TO PLAY

### 🌐 In your browser, right now
**[super-jackpot-roulette-win-extra-bi.vercel.app](https://super-jackpot-roulette-win-extra-bi.vercel.app/)**. Works on desktop and phone.

### 💻 Locally

It's plain HTML/CSS/JS with Three.js from a CDN: no build step, no `npm install`, no nonsense. You just need a tiny local server, because browsers refuse to load ES modules from `file://`.

```bash
node scripts/dev-server.js
```

Then open **http://localhost:5173** and lose responsibly.

### 🌍 Deploying
It's a static site. [vercel.json](vercel.json) tells Vercel to serve the folder as-is (no framework, no build). Any static host works: Vercel, Netlify, GitHub Pages, a potato with nginx.
